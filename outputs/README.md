# MATLAB verification results

This folder contains overlays for the ten images in [data](../data), the nine-stage pipeline for `cell0003.png`, and a tab-separated sample table. Its columns are image stem, cell type, ELPV label, detector flag, and skeleton pixel count.

On 2,223 confidently labelled ELPV cells, the detector returned 1,446 true negatives, 62 false positives, 348 false negatives, and 367 true positives.

The overlays and pipeline visualize processed or annotated ELPV images from [ZAE Bayern and the dataset authors](https://github.com/zae-bayern/elpv-dataset), under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
