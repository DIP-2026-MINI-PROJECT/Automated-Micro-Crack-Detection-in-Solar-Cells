# ELPV input samples

The ten PNGs in this folder are unmodified input images from the [ELPV Defective Solar Cells Dataset](https://github.com/zae-bayern/elpv-dataset) by ZAE Bayern and the dataset authors. The source images are distributed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). For the full MATLAB evaluation, download the complete ELPV dataset and retain its `elpv_dataset/data/labels.csv` and `elpv_dataset/data/images/` layout.
